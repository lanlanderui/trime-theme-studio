> **依据**：`doc/design/ui-directions.html` 的 **方向 B 三屏**（B1 主题列表 / B2 配色 / B3 键盘编辑）

> 前置：`doc/ui-skin-plan.md` 的皮肤管道（token / overlay / 运行时切换）已经落地，本文是它之上的
> **重排与改造流程**，不推翻管道，只重定「做什么、按什么顺序、怎么算对上」。

## 0. 一句话结论

把 B 从「可选皮肤」提升为**主实现**：先用 F0 把 token 数字改到与稿子一致并冻结，再用 F1–F4
逐屏按稿重做结构（B1 英雄区 + 行、B2 一组一屏 + 大色块 + 主色 dock、B3 舞台 + 大字段 + 悬浮 dock），
每屏过一道**设计核对闸门**（逐条勾规格号 + 截图并排）。三处关键取舍（舞台内边距 vs 预览像素闸门、
一组一屏 vs 查找效率、平板两栏 vs 稿子单栏）必须先定，否则后面返工。

## 4. 必须现在定的取舍（每条都给了推荐与代价）

### 4.1 舞台内边距 vs 预览像素闸门（**最硬的冲突**）

稿子 B3 让键盘缩进舞台 10dp（`.kb{padding:0 10px}`）。但键盘预览的宽度必须与输入法一致，
差 1dp 键位就重排，"预览即所得"就不成立——这是 03 期 D2 闸门的前提。

| 选项 | 结果 |
|---|---|
| **推荐：舞台底铺满、键盘仍通栏** | 只在键盘背后铺渐变色，左右不加内边距；视觉上是"键盘压在舞台上"，与稿子差别仅在键宽 20dp。像素闸门保住 |
| 严格照稿缩进 10dp | 预览宽度 -20dp，键宽误差 ~2%，D2 闸门作废，且用户看到的键盘与真机不同 |

**需你确认**：接受"通栏"还是接受"预览与真机不再一致"。

### 4.2 一组一屏 vs 找值的效率

54 个色值按稿分 4 段（候选栏/键盘/状态/方案），实际是 8 组，映射建议：

| 段控 | 覆盖的组 |
|---|---|
| 候选栏 | 候选栏与编码区（11）、候选高亮（6） |
| 键盘 | 键盘（12）、按键气泡（5） |
| 状态 | 状态栏与导航栏（4）、其他（4） |
| 方案 | 配色方案管理（3 动作 + 方案名） |

代价：找第 47 个色值要从"滚一屏"变成"切段 + 滚"。**缓解**：段控右侧放组内项数，切换时保留滚动位置。

### 4.3 平板两栏 vs 稿子单栏

稿子是 340dp 手机。平板上如果保留左侧目录栏，英雄区会被挤到内容列里，舞台只剩一半宽。
**推荐**：≥600dp 时**收起目录栏**，改用顶部段控（即 B2-02 的段控承担导航）——
这也顺带解决 F3 里"配色页不再用 Preference + rail"的结构问题。

### 4.4 dock 用字形还是图标

稿子用 `＋ ⇄ ⤓ ⌨` 这类字形。仓库里有 `cmd_*` 图标库（与输入法同一套）。
**推荐**：用图标 + 8.5sp 文字（更耐看、缩放不糊），接受与稿子的字形略有差异，并把这条记进偏差表。

### 4.5 B 与既有两套皮肤的关系

F2–F5 会让 `proof` 与 `m3-tonal` 在结构上落后（它们仍是旧骨架）。三条路：

| 选项 | 代价 |
|---|---|
| **推荐**：B 完成后，把 B 的结构定为唯一骨架，`tonal` 只换 token（形状/字阶/色），`proof` 冻结为"仅颜色可用" | 两套旧皮肤的结构会与 B 不一致，需要在 README 里说清 |
| 三套各维护一套结构 | 回归面 ×3，不可能持续 |
| 删掉 `proof` | 少一个回退选项，但代码最干净 |

## 5. 失败条件（F6 判定用）

任一条触发即不算通过：

1. 舞台内边距导致键盘预览与真机键位不一致（§4.1 选了"严格照稿"则豁免）。
2. 54 个色值有任何一个在 B2 里找不到（可以分屏，不可以消失）。
3. 写盘行为变化：`theme-core` 用例有任何一条结果不同，或 create→delete 不再逐字节 no-op。
4. dock 遮挡内容：滚到底部时最后一个字段/行被压住，且没有 96/84 的余量。
5. 暗色下暖色发脏：正文对比度 < 4.5:1，或强调色在深底上变成铁锈块。
6. 平板（848dp）下英雄区高度超过屏高 40%，把「其余主题」挤出首屏。
7. 21–24dp 小字在平板上成片发灰（spec 代价里点名的那条）。

## 6. 推进顺序（可照做）

```
F0 冻结基线  ──► F1 舞台/dock ──► F2 主题列表 ──┐
                              ├─► F3 配色页   ──┼─► F5 其余五页 ──► F6 收敛
                              └─► F4 键盘编辑 ──┘
```

每一步的收尾动作固定三条：① 该屏 5 张截图（亮/暗 × 手机/平板 + 一张与稿并排）；
② 勾 §1 对应规格号；③ 四道门禁（`spotlessKotlinCheck` / `test` / `lintDebug` / `assembleDebug`）。

开工前需要你拍板的三件事（都在 §4）：**4.1 舞台内边距**、**4.3 平板收起目录栏**、**4.5 旧皮肤怎么处置**。
其余（4.2 映射、4.4 图标）我按推荐执行，并在偏差表里记录。
